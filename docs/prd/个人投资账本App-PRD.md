# 个人投资账本 App 产品需求文档

## 1. 产品目标

为个人提供一个手机端投资账本，记录股票、债券、基金、现金和货币基金的交易及资产变化，帮助用户每天了解：

- 今天资产变化了多少。
- 实际投入资金的年化收益是多少。
- 投资是否跑赢银行存款或货币基金。
- 获得当前收益承担了多少风险。

## 2. 第一阶段范围

支持股票、债券、基金、现金和货币基金；支持手动录入交易，并支持通过截图识别交易信息后由用户确认导入。资讯和量化指标作为后续阶段能力。

## 3. 首页展示需求

首页采用“先看结果，再看原因”的布局。

### 3.1 今日资产卡片

展示：

- 当前总资产。
- 今日资产变化金额。
- 今日收益率。
- 可用现金。

示例：

```text
今日资产
¥102,680.00
今日 +¥680.00（+0.67%）
```

今日变化需要区分市场涨跌、资金转入转出、交易费用和分红利息，避免把新增本金误显示为投资收益。

### 3.2 年化收益卡片

展示：

- 资金加权年化收益率（XIRR）。
- 银行存款或货币基金基准收益率。
- 相对基准的超额收益。
- 数据计算起止日期。

示例：

```text
我的年化收益率
8.62%
基准收益率 3.00%
跑赢基准 +5.62%
```

数据不足以计算年化收益时，展示累计收益并说明缺少的交易或估值数据，不使用零值代替。

### 3.3 收益构成卡片

展示：

- 已实现收益。
- 未实现收益。
- 分红和利息。
- 手续费及税费。
- 累计总收益。

示例：

```text
收益构成
已实现收益    ¥3,200
未实现收益    ¥6,480
分红/利息     ¥800
手续费税费    -¥320
```

### 3.4 资产配置卡片

以环形图或横向条形图展示股票、基金、债券、现金和货币基金占总资产的比例，并显示各类资产金额。

示例：

```text
股票 45%   基金 30%   债券 15%   现金 10%
```

### 3.5 风险情况卡片

展示：

- 最大回撤。
- 波动率。
- 持有天数。
- 亏损持续时间（可选）。

示例：

```text
风险情况
最大回撤    -8.4%
波动率      12.1%
持有天数    386天
```

### 3.6 最近记录

展示最近的买入、卖出、申购、赎回、分红、利息、转入和转出记录，并标识截图识别待确认记录。

## 4. 底部导航

```text
首页　交易　持仓　复盘
```

- 首页：总资产、今日收益、年化和风险概览。
- 交易：新增、编辑、删除和查询交易记录。
- 持仓：查看各标的数量、成本、估值和收益。
- 复盘：查看收益曲线、基准比较和风险分析。

## 5. 基金详情页

基金详情页展示：

```text
基金名称：某基金
当前市值：¥2,200
投入本金：¥2,000
累计收益：¥200
收益率：10.00%
资金加权年化：20.00%
持有天数：365天
最大回撤：-6.2%
基准收益：3.00%
超额收益：+17.00%
```

同时展示：

- 每笔买入和卖出记录。
- 当前持仓份额。
- 持仓成本和单位成本。
- 已实现收益与未实现收益。
- 分红、赎回费和其他费用。
- 净值或估值变化曲线。

## 6. 复盘页面

复盘页面提供：

- 累计收益曲线。
- 年化收益率曲线。
- 与银行存款或货币基金基准的对比曲线。
- 每月收益统计。
- 最大回撤和波动率。
- 股票、债券、基金、现金对总收益的贡献。
- 投入资金和取出资金时间线。
- 基于数据的持有复盘提示。

复盘提示只能描述数据，例如“过去一年跑赢基准 4.2%”“最大回撤为 12%”，不直接生成确定性的买卖建议。

## 7. 收益计算口径

### 7.1 总收益率

```text
总收益率 =（当前总资产 - 累计投入本金 + 累计取出资金）÷ 累计投入本金
```

实际实现时还需纳入分红、利息、手续费和税费。

### 7.2 资金加权年化收益率

使用 XIRR，根据每笔资金流发生的日期计算：

- 买入或外部转入：负现金流。
- 卖出、分红、利息或外部转出：正现金流。
- 期末仍持有的资产：按期末市值作为正现金流。
- 手续费和税费计入收益损耗。

### 7.3 买卖期间的处理

买入和卖出本身属于资金流，不直接等于收益。收益由卖出金额、期末持仓市值、分红利息、投入本金及费用共同决定。部分卖出时，按照用户选择的先进先出法或加权平均成本法结转成本。

## 8. 截图导入

1. 用户拍照或选择券商、银行、基金平台截图。
2. 系统识别日期、标的、交易方向、份额、价格、金额、费用和账户。
3. 以表单形式展示识别结果和置信度。
4. 低置信字段高亮，用户确认或修改。
5. 确认后写入交易账本并重新计算持仓和收益。
6. 原图由用户选择是否保留。

OCR 识别失败时允许手动录入，不自动生成未经确认的交易。

## 9. 视觉规范

- 绿色：盈利和跑赢基准。
- 红色：亏损和回撤。
- 灰色：本金、现金流和辅助信息。
- 蓝色：基准、统计和分析信息。
- 金额、收益率和年化收益率使用统一小数位和千分位格式。
- 重要数据优先使用卡片展示，详细数据进入详情页。

## 10. 验收标准

- 首页能同时显示总资产、今日盈亏、年化收益率和基准比较。
- 今日资产变化能区分投资收益与本金转入转出。
- 基金中途追加买入或部分卖出后，已实现收益、未实现收益和 XIRR 均能更新。
- 截图识别结果必须经用户确认才可入账。
- 修改或删除交易后，持仓、收益、曲线和风险指标同步更新。
- 收益展示包含费用和税费影响。
